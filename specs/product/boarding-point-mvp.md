# 탑승 지점 MVP

## 제품 전제

Dash는 사용자가 탈 버스 노선을 이미 알고 있다는 전제의 출퇴근용 도착 정보 앱이다. 현재 MVP는 **탑승 지점 → 정류장 → 노선** 순서로 설정한다. 노선을 먼저 고르는 추가 흐름은 구현하지 않았으며 후속 범위다.

## 화면 구성

1. 현재 탑승 지점: 현재 지점의 선택 노선 도착 정보를 표시한다.
2. 탑승 지점 목록: 현재 지점을 바꾸고 탑승 지점을 추가·편집·삭제한다.
3. 탑승 지점 편집: 이름, 포함 정류장, 정류장별 선택 노선을 편집한다.
4. 정류장 추가: 지도와 검색 결과로 정류장을 고른다.
5. 버스 노선 선택: 한 정류장에서 추적할 노선을 복수 선택한다.

## 현재 탑승 지점

- 최초 진입에서는 저장 설정을 읽은 뒤 현재 위치를 요청한다.
- 선택 노선이 하나 이상인 탑승 지점 중 현재 위치와 가장 가까운 지점을 항상 우선 선택한다.
- 위치 권한이 없거나 위치를 얻지 못했을 때만 저장된 현재 지점을 fallback으로 사용한다.
- 위치 기반 자동 선택과 다음 지점 전환에서는 선택 노선이 없는 탑승 지점을 제외한다.
- 제목 영역을 누르면 저장 순서상 다음 유효 탑승 지점으로 전환하고 선택을 저장한다.
- 위치 버튼은 현재 위치 기준 선택을 다시 수행하고, 새로고침 버튼은 현재 지점의 도착 정보를 다시 조회한다.
- 앱이 active 상태가 될 때마다 유효한 현재 지점이 있고 조회 중이 아니라면 도착 정보를 다시 조회한다.
- 여러 정류장의 조회는 병렬 실행하며 일부만 성공해도 성공 결과를 표시한다. 모든 정류장 조회가 실패했을 때만 전체 오류로 처리한다.
- 도착 예정 항목은 도착 시각 순으로 정렬하고 최대 5개를 표시한다.
- 각 항목은 노선 번호, 절대 도착 시각, 올림한 잔여 분을 표시한다. 잔여 시간은 3분 이하는 bold, 4~10분은 regular, 그 이후는 light로 강조도를 낮춘다.
- 성공한 조회 시각은 10초가 지난 뒤 `12초 전`, `2분 전`, `1시간 전`과 같은 한국어 경과 시간으로 표시한다.
- 설정 조회, 도착 조회, 설정 저장 실패에는 사용자용 메시지와 재시도 경로를 제공한다.

## 탑승 지점 목록

- 행에는 탑승 지점 이름과 `N개 노선 · 노선 번호` 요약을 표시한다.
- 행 탭은 해당 지점을 현재 지점으로 선택하고 첫 화면으로 돌아간다.
- 현재 지점은 민트 배경, 왼쪽 rail, 강조된 제목으로 표시한다.
- 편집과 삭제는 행의 별도 액션이다. 삭제는 확인을 거치며 마지막 탑승 지점은 삭제할 수 없다.
- 추가 액션은 비어 있는 draft를 만들고 편집 화면으로 이동한다.

## 탑승 지점 편집

- 이름만 필수이며 저장 시 앞뒤 공백을 제거한다.
- 정류장 0개 및 선택 노선 0개인 상태도 저장할 수 있다.
- 정류장 행은 이름, API `stopID`, 선택한 노선 요약을 표시한다. 행 탭은 노선 선택으로 이동한다.
- 정류장 삭제는 저장 전 draft에 즉시 반영한다.
- 기존 지점은 화면 하단에서 삭제할 수 있으며 확인을 거친다. 새 지점에는 삭제 액션이 없다.
- 새 지점 ID는 소문자 UUID 문자열이다. 저장 후 목록에 추가되며 자동으로 현재 지점이 되지는 않는다.

## 정류장 추가

- 화면 상단에는 1:1 지도와 검색 overlay를 표시하며 지도 범위는 가로·세로 약 300m다.
- 진입 시 위치를 얻으면 서울·경기 주변 정류장을 조회한다. 위치를 얻지 못해도 이름 또는 번호 검색은 사용할 수 있다.
- 검색 및 주변 조회는 서울·경기 요청을 병렬 실행한다. 한 지역만 성공해도 그 결과를 표시하고 두 요청이 모두 실패했을 때만 오류로 처리한다.
- 새 결과가 도착하면 지도를 첫 결과로 이동하지만 정류장을 자동 선택하지는 않는다.
- 지도 marker와 목록 행은 결과 순서의 A~Z 문자를 공유한다. 선택 marker는 민트, 나머지는 보조색이다.
- marker 또는 행을 선택하면 지도가 해당 정류장으로 즉시 이동하고, 선택 행을 목록 최상단으로 즉시 스크롤한다.
- 선택 행은 애니메이션 없이 아래로 확장된다. 선택한 정류장에 대해서만 경유 노선을 조회한다.
- 상세 영역은 최대 6개 노선 번호와 나머지 개수, 조회 중 문구, 오류 및 재시도, 행 전체 폭의 `이 정류장 추가` 액션을 상태에 맞게 표시한다.
- 경유 노선 조회 중에도 정류장 추가 액션은 사용할 수 있다.
- 이미 draft에 포함된 정류장은 중복 추가하지 않는다.

## 버스 노선 선택

- 정류장 이름과 API `stopID` 아래에 노선 번호를 자연 정렬한 adaptive grid로 표시한다.
- 이미 선택된 노선이 최신 API 응답에 없어도 선택 목록에 보존한다.
- 선택 상태는 민트 8% 배경과 원형 check로 표시하며, card stroke는 바꾸지 않는다.
- 섹션 헤더에 `N개 선택`을 표시한다. 모두 선택/해제 및 별도 하단 선택 개수 영역은 없다.
- 선택이 0개이면 `완료`를 비활성화한다. 따라서 기존 선택을 모두 지운 상태로 완료할 수 없다.
- 로딩, 빈 결과, 오류 및 재시도 상태를 제공한다.

## 의도적인 MVP 범위

- 최초 설치에는 영등포역과 더현대서울 샘플 탑승 지점이 포함된다.
- 별도 온보딩 없이 샘플 데이터에서 시작한다.
- 노선 우선 추가 흐름은 후속 작업이다.
- iOS의 현재 배포 대상과 기기 범위는 iOS 프로젝트 설정을 따른다. Android는 새 프로젝트 생성 시 최신 Android Studio 기본값을 먼저 사용하고 별도 변경은 근거가 생길 때 결정한다.
