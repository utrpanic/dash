# 탑승 지점 화면 디자인 언어

공통 spacing, typography, size, radius, surface, selection과 화면 template은 [`design-system.md`](design-system.md)를 따른다. 이 문서는 탑승 지점 도메인의 정보 구조와 화면별 예외만 정의한다.

## 범위

이 문서는 다음 다섯 화면에 공통으로 적용한다.

1. 현재 탑승 지점 화면
2. 탑승 지점 목록 화면
3. 정류장 추가 화면
4. 탑승 지점 편집 화면
5. 버스 노선 선택 화면

화면과 접근성 문구에서는 `승차 지점` 대신 `탑승 지점`을 사용한다.

## 세 층의 문법

화면 일관성은 모든 데이터를 같은 모양으로 만드는 것이 아니라 다음 세 층을 분리해 유지한다.

1. 엔티티 정체성: 같은 Boarding point, Stop, Route는 화면이 달라도 정보 순서와 시각적 중심을 유지한다.
2. 화면 모드: 보기, 선택, 편집에 따라 카드, 평면 행, grouped surface 같은 외부 컨테이너가 달라진다.
3. 상태 표현: 현재 사용 중, 지도에서 임시 선택, 다중 체크를 서로 다른 표시로 구분한다.

### Boarding point

- 표준형: 이름 → `N개 노선 · 노선 번호`
- 현재 화면 선택기의 compact형: 위치 아이콘 → 이름 → chevron
- 편집형: 이름 입력 → 정류장 수와 선택 노선 수

### Stop

- 기본 순서: 정류장명 → 정류장 번호
- 정류장 추가 검색 목록은 서울 `arsID`를 우선하지만, 현재 편집 및 노선 선택 화면은 API `stopID`를 표시한다.
- 검색형은 정류장 번호 다음에 거리를 표시할 수 있다.
- 편집형은 고정 정보 다음에 선택 노선 요약을 추가한다.
- 별칭은 기본 UI에 표시하지 않는다. 여러 정류장을 구분하기 위한 탑승 지점별 별칭은 실제 필요가 확인된 뒤 별도 설계한다.
- A/B/C 마커는 지도 핀과 목록을 연결할 때만 사용하며, 지도 없는 편집 화면에는 표시하지 않는다.

### Route

- 노선 번호를 가장 강한 요소로 사용한다.
- 현재 선택형은 노선 번호만 grid tile 중앙에 표시한다. 방향과 다음 정류장은 현재 데이터 및 UI 계약에 포함하지 않는다.
- 도착 상태형은 같은 노선 번호 중심 구조에 절대 도착 시각과 남은 시간을 추가한다.

## 공통 패턴 적용

- 현재 탑승 지점: `StatusDashboard`
- 탑승 지점 목록: `FlatEntityList` + 단일 선택
- 탑승 지점 편집: `FormEditor`
- 정류장 추가: `MapSingleSelect`
- 버스 노선 선택: `MultiSelectList`

## 화면별 예외

### 현재 탑승 지점

- 현재 지점 선택기와 편집·목록 버튼을 상단에 유지한다.
- 자동 최근접 선택과 다음 지점 전환은 선택 노선이 하나 이상인 탑승 지점만 대상으로 한다.
- 사용자가 선택 노선이 없는 탑승 지점을 직접 선택하면, 도착 정보 빈 상태와 구분되는 설정 안내를 표시한다.
- 도착 카드에는 노선 번호, 절대 도착 시각, 남은 시간을 가장 강한 위계로 표시한다.
- 남은 시간 단위는 `분`, 마지막 업데이트는 `12초 전`, `2분 전`, `1시간 전` 같은 한국어 경과 시간으로 표시한다.
- 위치와 새로고침 버튼은 서로 겹치지 않는 원형 플로팅 버튼으로 배치한다.
- 도착 카드 목록은 분류가 하나뿐이므로 별도의 섹션 헤더를 표시하지 않는다.
- 마지막 업데이트 시각은 새로고침 버튼 아래에 표시해 해당 액션과 직접 연결한다.

### 탑승 지점 목록

- 행 탭은 현재 탑승 지점 선택, 연필 버튼은 편집, 휴지통 버튼은 삭제로 역할을 분리한다.
- 탑승 지점 삭제는 확인 후 수행하며, 마지막 탑승 지점의 삭제 버튼은 비활성화한다.
- 현재 선택 행만 공통 민트 선택 패턴을 적용한다.
- 목록 외곽을 rounded container로 묶지 않는다. 선택 배경, selection rail과 평면 행이 같은 16pt 목록 영역 안에서 정렬되어야 한다.

### 탑승 지점 편집

- 이름, 정류장 수, 선택 노선 수를 한 화면에서 확인할 수 있어야 한다.
- 정류장 행은 정류장 추가 화면과 같은 flat list 문법을 사용한다.
- 정류장 행 탭은 버스 노선 선택으로 이동하고, trailing 휴지통 버튼으로 정류장을 draft에서 바로 삭제한다.
- Stop의 정류장명·정류장 번호 순서는 선택 화면과 동일하게 유지한다.
- 지도 전용 A/B/C 마커는 사용하지 않는다.

### 정류장 추가

- 지도와 목록은 A~Z marker로 같은 검색 결과를 연결한다.
- 새 검색 결과는 지도만 첫 결과로 이동하고 자동 선택하지 않는다.
- 선택 시 marker, 지도 focus, 목록 선택, 최상단 scroll이 하나의 상태로 즉시 바뀐다.
- 선택 행의 기존 요약 영역은 위치와 높이를 유지하고 상세 영역만 아래에 추가한다.
- 확장 영역에는 경유 노선 요약과 `이 정류장 추가` 버튼을 표시한다. 버튼은 행 전체를 대상으로 보이도록 콘텐츠 폭을 채우며 경유 노선 조회 중에도 활성 상태를 유지한다.

### 버스 노선 선택

- 상단에는 정류장명과 API `stopID`를 표시한다.
- 정류소 경유 노선은 데이터 소스에서 주입받으며, 기존 선택 노선은 주입 목록에 없어도 유지한다.
- 노선 번호만 adaptive grid의 selectable tile로 표시해 빠르게 비교하고 선택한다.
- 다중 선택은 민트 8% 배경과 오른쪽 위 check circle을 사용한다. stroke를 강조하거나 selection rail을 사용하지 않는다.
- 선택 개수는 `노선` 섹션 헤더 오른쪽에 `N개 선택`으로 한 번만 표시한다.
- `모두 선택`, `모두 해제` 및 하단 선택 개수 영역은 사용하지 않는다.
- 선택이 0개이면 내비게이션의 `완료` 액션을 비활성화한다.
