# 탑승 지점 화면 디자인 언어

공통 spacing, typography, size, radius, surface, selection과 화면 template은 [`design-system.md`](design-system.md)를 따른다. 이 문서는 탑승 지점 도메인의 정보 구조와 화면별 예외만 정의한다.

## 범위

이 문서는 다음 다섯 화면에 공통으로 적용한다.

1. 현재 탑승 지점 화면
2. 탑승 지점 목록 화면
3. 정류장 추가 화면
4. 탑승 지점 편집 화면
5. 버스 노선 선택 화면

화면과 접근성 문구에서는 `승차 지점` 대신 `탑승 지점`을 사용한다.

## 세 층의 문법

화면 일관성은 모든 데이터를 같은 모양으로 만드는 것이 아니라 다음 세 층을 분리해 유지한다.

1. 엔티티 정체성: 같은 Boarding point, Stop, Route는 화면이 달라도 정보 순서와 시각적 중심을 유지한다.
2. 화면 모드: 보기, 선택, 편집에 따라 카드, 평면 행, grouped surface 같은 외부 컨테이너가 달라진다.
3. 상태 표현: 현재 사용 중, 지도에서 임시 선택, 다중 체크를 서로 다른 표시로 구분한다.

### Boarding point

- 표준형: 이름 → `N개 노선 · 노선 번호`
- 현재 화면 선택기의 compact형: 위치 아이콘 → 이름 → chevron
- 편집형: 이름 입력 → 정류장 수와 선택 노선 수

### Stop

- 기본 순서: 정류장명 → 정류장 번호
- 검색형은 정류장 번호 다음에 거리를 표시할 수 있다.
- 편집형은 고정 정보 다음에 선택 노선 요약을 추가한다.
- 별칭은 기본 UI에 표시하지 않는다. 여러 정류장을 구분하기 위한 탑승 지점별 별칭은 실제 필요가 확인된 뒤 별도 설계한다.
- A/B/C 마커는 지도 핀과 목록을 연결할 때만 사용하며, 지도 없는 편집 화면에는 표시하지 않는다.

### Route

- 노선 번호를 항상 가장 강한 왼쪽 요소로 사용한다.
- 선택형은 방향과 다음 정류장을 표시한다.
- 도착 상태형은 같은 노선 번호 중심 구조에 절대 도착 시각과 남은 시간을 추가한다.

## 공통 패턴 적용

- 현재 탑승 지점: `StatusDashboard`
- 탑승 지점 목록: `FlatEntityList` + 단일 선택
- 탑승 지점 편집: `FormEditor`
- 정류장 추가: `MapSingleSelect`
- 버스 노선 선택: `MultiSelectList`

## 화면별 예외

### 현재 탑승 지점

- 현재 지점 선택기와 편집·목록 버튼을 상단에 유지한다.
- 도착 카드에는 노선 번호, 절대 도착 시각, 남은 시간을 가장 강한 위계로 표시한다.
- 남은 시간 단위와 마지막 업데이트 문구는 각각 `분`, `N시간 전 업데이트`처럼 한국어로 표시한다.
- 위치와 새로고침 버튼은 서로 겹치지 않는 원형 플로팅 버튼으로 배치한다.
- 마지막 업데이트 시각은 콘텐츠 섹션 헤더에서 한 번만 표시한다.

### 탑승 지점 목록

- 행 탭은 현재 탑승 지점 선택, 연필 버튼은 편집으로 역할을 분리한다.
- 현재 선택 행만 공통 민트 선택 패턴을 적용한다.
- 목록 외곽을 rounded container로 묶지 않는다. 선택 배경, selection rail과 평면 행이 같은 16pt 목록 영역 안에서 정렬되어야 한다.

### 탑승 지점 편집

- 이름, 정류장 수, 선택 노선 수를 한 화면에서 확인할 수 있어야 한다.
- 정류장 행 탭은 버스 노선 선택으로 이동하고, 별도 메뉴가 삭제를 담당한다.
- Stop의 정류장명·정류장 번호 순서는 선택 화면과 동일하게 유지한다.
- 지도 전용 A/B/C 마커는 사용하지 않는다.
