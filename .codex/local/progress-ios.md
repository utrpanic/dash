## 확인 사항

1. 탑승 지점 추가·편집·삭제 결과는 즉시 메모리 상태에 반영된 뒤 SwiftData에 순차 저장되며, 실패 시 최신 상태를 보존해 사용자 재시도를 지원.
2. 최초 V1 DB는 정류장 지역과 서울 ARS 번호를 명시적으로 저장·복원하며, 기존 개발 DB는 앱 삭제 후 재설치해 초기화.
3. 앱 실행 시 저장된 선택을 먼저 노출하지 않고 현재 위치 확인을 우선하며, 위치 권한 거부·위치 수신 실패 시에만 마지막 저장 선택을 사용.
4. 시뮬레이터 위치 검증은 한국 모의 좌표를 지정해 진행; 첫 화면의 최근접 선택만으로 실제 위치 수신 성공을 판단하지 않음.
5. 단계 3 검증: 선택·저장 정책 테스트와 SwiftData 디스크 재오픈 테스트를 묶어 10개 통과했으며 Dash Simulator 빌드도 통과.
6. 새 설치 시 예제 탑승 지점을 생성하고 첫 등록 흐름을 제한하는 정책은 의도된 MVP 결정.
7. MVP 개선 검증: 네트워크 통합 테스트를 포함한 Feature 테스트 44개와 iPhone 17 Simulator 대상 Dash 앱 빌드 통과.
